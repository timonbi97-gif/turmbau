# Turmbau

Ein Physik-Turmbauspiel, gemacht mit Unity. Blöcke fallen von oben – richte sie aus und baue den höchsten Turm, ohne dass er umkippt!

**Direkt im Browser spielen:** https://timonbi97-gif.github.io/turmbau/

## Neu in Version 1.1
- **Höhenzonen:** Wiese → Windige Höhen (Windböen) → Sturmwolken (Regen, Blitze) → Weltraum (geringe Schwerkraft)
- **FEVER-Modus:** 4x PERFEKT in Folge = 15 Sekunden doppelte Münzen
- **Missionen** mit Münz-Belohnungen und ein **täglicher Bonus**
- **Rekordlinie** im Spiel – überhol deinen eigenen Rekord!
- Neue Optik: Himmel, der sich mit der Höhe verändert, Partikeleffekte, Leuchteffekte, texturierte Blöcke

Steuerung: A/D oder Pfeiltasten (oder Maus ziehen) zum Bewegen, Q/E zum Drehen, Leertaste zum Fallenlassen. Auf dem Handy: wischen und die Knöpfe benutzen.
